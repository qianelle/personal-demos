# personal-demos
个人 Demo 与项目作品集：收录低代码系统搭建、自动化系统搭建、业务流程配置案例，附项目说明、截图、操作手册与数据字典，用于学习沉淀与求职展示。

## 项目一览

| 项目 | 技术/平台 | 一句话 | 材料 |
|---|---|---|---|
| 通用仓库管理系统 | 钉钉宜搭 | 主数据 → 出入库审批 → 库存台账闭环 | [项目案例](./warehouse/README.md) · 截图 · 操作手册 |
| 通用人事管理系统 | 钉钉宜搭 | 员工档案 → 请假审批 → 入转调离并行会签 | [项目案例](./hr/README.md) · 截图 · FAQ |

## 目录说明
- `docs/` 项目案例、操作说明、FAQ 与问题库、数据字典
- `screenshots/`项目截图

所有业务数据均为模拟数据；部分配置受单人组织与平台免费版限制，降级口径见各项目的数据字典。
