# 通用仓库管理系统

## 1. 系统概述

面向通用办公与通用仓库场景的物资管理系统，覆盖物品主数据、出入库审批、库存台账与盘点三类业务。系统基于钉钉宜搭低代码平台构建，包含 7 张业务表单、3 个数据看板页与 2 条审批流程（出入库审批、盘点复核）。

## 2. 建设目标

| 目标 | 说明 |
| --- | --- |
| 主数据统一 | 统一物品编码、分类、计量单位与库位口径，形成唯一物品来源 |
| 业务在线化 | 出入库全程在线申请、审批与确认，申请原始信息不可改写 |
| 台账可追溯 | 当前结存与历史变动分表存储，支持对账、盘点与低库存预警 |

## 3. 系统结构

| 模块 | 业务表单 | 数据看板 | 说明 |
| --- | --- | --- | --- |
| 物品主数据 | 物品档案 | 物品档案数据看板 | 1 张主数据表、3 个视图、3 张报表 |
| 出入库申请 | 出入库申请单（含单据明细子表单） | 出入库数据看板 | 1 条审批流程、3 张报表 |
| 库存台账与盘点 | 仓库库位、库存结存、库存流水、盘点单 | 库存看板 | 4 张表、4 个看板组件 |

## 4. 功能模块

### 4.1 物品主数据

- 物品档案记录编码、名称、分类、规格型号、计量单位、默认库位、安全库存、参考单价、状态、图片与备注。
- 编码按分类缩写分段，停用物品保留档案但不参与下游单据选择。
- 提供「在用物品」「停用物品」「按分类」三个视图；看板包含分类分布、在用/停用数量与库位明细。

### 4.2 出入库申请

- 单据主表记录单据编号、类型、申请日期、申请人、申请部门、总数量、总金额、事由与凭证附件。
- 单据明细以子表单逐行登记物品、库位、数量、单价、金额小计与行备注；选中物品后分类、单位、库位、单价自动带出，金额与汇总由公式计算。
- 审批按金额与数量规则分流，仓管确认环节仅开放必要字段的编辑权限。

### 4.3 库存台账与盘点

- 仓库库位维护「区-架-层」编码、所属区域、库位类型与状态。
- 库存结存一物一行，记录当前数量、安全库存与上次盘点日。
- 库存流水一笔一条，记录来源单号、单据类型、变动数量、变动后结存与变动时间，用于事后对账。
- 盘点单以子表单登记账面数量、实盘数量、差异与差异原因，并支持盘点范围与现场照片。
- 库存看板提供结存明细、低库存预警、出入库趋势与变动笔数。

## 5. 数据规模

| 数据集 | 记录数 | 说明 |
| --- | --- | --- |
| 物品档案 | 20 | 5 个分类；在用 18、停用 2 |
| 仓库库位 | 12 | 可用 10、停用 2 |
| 库存结存 | 20 | 按物品编码一物一行 |
| 库存流水 | 3 | 变动数量合计 206 |
| 出入库申请单 | 2 | 单据金额 111.00 与 5025.00，合计 5136.00 |
