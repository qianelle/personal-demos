# 通用仓库管理系统 · 操作手册

## 1. 角色与权限

| 角色 | 主要职责 | 数据范围 |
| --- | --- | --- |
| 主数据维护人 | 维护物品档案与仓库库位、执行批量导入与导出 | 主数据全部记录 |
| 申请人 | 发起出入库申请、查看本人单据进度 | 本人提交的单据 |
| 审批人 | 审批出入库申请、执行加签节点 | 待办范围内的单据 |
| 仓管 | 核对实物、确认单据、登记库存台账、执行盘点 | 全部业务单据与台账 |
| 查询角色 | 查看物品档案、台账与报表 | 只读 |

## 2. 物品档案维护

### 2.1 新增物品

1. 进入「物品档案」页面，点击「新增」。
2. 填写物品编码、物品名称、物品分类、规格型号、计量单位、默认库位、安全库存、参考单价与物品状态。
3. 物品编码须与分类缩写一致，编码规则见 `DATA_DICTIONARY.md`。
4. 上传物品图片并填写备注后保存。

### 2.2 批量导入

1. 在「数据管理」中导出模板，按模板列顺序填写数据。
2. 导入前对物品编码列做重复值检查，确保编码唯一。
3. 导入文件中仅保留需要新增的记录行，不包含系统中已存在的记录。
4. 选择「仅新增数据」并逐列核对字段映射；图片列与系统字段列可跳过映射。
5. 导入完成后按物品编码排序，核对记录总数与编码连续性。

### 2.3 停用物品

物品不再使用时，将「物品状态」改为「停用」并在备注写明原因，不删除记录。停用物品不再出现在出入库申请单的物品选择列表中。

### 2.4 查询与视图

| 视图 | 用途 |
| --- | --- |
| 在用物品 | 日常可选物品清单 |
| 停用物品 | 已淘汰物品档案 |
| 按分类 | 按物品编码升序排列，同分类缩写自然聚合 |

## 3. 发起出入库申请

1. 进入「出入库申请单」，点击「新增」。
2. 填写单据编号、单据类型（入库 / 出库 / 退库）、申请日期、事由并上传凭证附件；申请人与申请部门由系统自动带出。
3. 在「单据明细」中新增一行，从「物品」下拉搜索物品名称并选中。
4. 系统自动带出物品分类、计量单位、默认库位与单价；填写「数量」后，金额小计、总数量与总金额自动计算。
5. 多物品时逐行添加明细，核对主表汇总无误后提交。

## 4. 审批与仓管确认

1. 审批人在「待我处理」中打开单据，核对明细与附件后选择同意或退回。
2. 符合加签规则的单据在完成主管审批后进入仓库负责人节点，规则见 `WORKFLOW.md`。
3. 仓管在确认节点核对实物，可修改数量、单价与默认库位三个字段；其余字段为只读。
4. 确认完成后流程结束，系统抄送申请人。

## 5. 库存台账登记

每完成一张出入库单，按明细逐行登记库存流水：

| 字段 | 填写规则 |
| --- | --- |
| 来源单号 | 对应的出入库单据编号，保证可追溯 |
| 单据类型 | 与来源单据一致 |
| 变动数量 | 入库为正、出库为负、退库按实际方向填写 |
| 变动后结存 | 本次登记完成后的实际结存数 |
| 变动时间 | 业务发生日期 |
| 备注 | 登记说明 |

登记后同步更新「库存结存」中对应物品的当前数量。结存表记录当前状态，流水表记录变动历史，两者不可相互替代。

## 6. 盘点

1. 新建「盘点单」，填写盘点单号、盘点日期、盘点范围、盘点人并上传现场照片。
2. 在「盘点明细」中逐行选择物品，填写账面数量与实盘数量。
3. 差异由公式自动计算；存在差异时须填写差异原因。
4. 填写盘点结论并提交复核，复核完成后更新「上次盘点日」。

## 7. 数据看板

| 看板 | 内容 |
| --- | --- |
| 物品档案数据看板 | 分类分布、在用/停用数量、库位明细 |
| 出入库数据看板 | 单据类型占比、部门申领排行、月度金额趋势 |
| 库存看板 | 库存结存明细、低库存预警、出入库趋势、变动笔数 |

## 8. 通用说明

- 标注只读的公式字段（金额小计、总数量、总金额、差异）不可手工改写，需修改来源字段后自动重算。
- 提交人、提交时间、修改时间等由系统自动记录。
- 数据导出前先通过视图或筛选确认范围，避免导出无关记录。
