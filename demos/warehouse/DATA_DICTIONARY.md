# 通用仓库管理系统 · 数据字典与编号规则

## 1. 编号规则

| 对象 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 物品编码 | `WL-{分类缩写}-{4位序号}` | `WL-BG-0001` | 缩写与物品分类严格一致 |
| 出入库单号 | `CRK-{yyyyMMdd}-{序号}` | `CRK-20261109-001` | 按业务日期与序号编制 |
| 库位编码 | `区-架-层` | `A-03-2` | 首字母与所属区域一致 |
| 盘点单号 | `PD-{yyyyMMdd}-{序号}` | `PD-20261110-001` | 按业务日期与序号编制 |

分类缩写对照：

| 缩写 | 物品分类 |
| --- | --- |
| BG | 办公用品 |
| BZ | 包装耗材 |
| QJ | 清洁用品 |
| SB | 设备配件 |
| QT | 其他 |

## 2. 表单清单

| 表单 | 类型 | 主键口径 | 数据量 |
| --- | --- | --- | --- |
| 物品档案 | 主数据表 | 物品编码 | 20 |
| 出入库申请单 | 流程表单（含子表单） | 单据编号 | 2 |
| 仓库库位 | 主数据表 | 库位编码 | 12 |
| 库存结存 | 台账表 | 物品编码 | 20 |
| 库存流水 | 流水表 | 来源单号 + 物品编码 | 3 |
| 盘点单 | 流程表单（含子表单） | 盘点单号 | 按需 |

## 3. 字段定义

### 3.1 物品档案

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 物品编码 | 单行文本 | 是 | 主键，唯一 |
| 物品名称 | 单行文本 | 是 | 下游关联表单的显示字段 |
| 物品分类 | 下拉单选 | 是 | 办公用品 / 包装耗材 / 清洁用品 / 设备配件 / 其他 |
| 规格型号 | 单行文本 | 否 | 如 A4 70g |
| 计量单位 | 下拉单选 | 是 | 个 / 箱 / 包 / 件 / 米 / 千克 |
| 默认库位 | 单行文本 | 否 | 区-架-层 |
| 安全库存 | 数值 | 否 | 非负整数，用于预警基准 |
| 参考单价 | 数值 | 否 | 两位小数，字段权限控制可见范围 |
| 物品状态 | 单选 | 是 | 在用 / 停用，默认在用 |
| 物品图片 | 图片 | 否 | 实物照片 |
| 备注 | 多行文本 | 否 | — |

### 3.2 出入库申请单

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 单据编号 | 单行文本 | 是 | 主键 |
| 单据类型 | 单选 | 是 | 入库 / 出库 / 退库 |
| 申请日期 | 日期 | 是 | 默认当天 |
| 申请人 | 成员 | 是 | 默认当前登录人 |
| 申请部门 | 部门 | 是 | 默认当前登录人所属部门 |
| 总数量 | 数值 | 否 | 公式：明细数量求和，只读 |
| 总金额 | 数值 | 否 | 公式：明细金额小计求和，只读，两位小数 |
| 事由 | 多行文本 | 是 | — |
| 凭证附件 | 附件 | 否 | 送货单 / 申领单 |

单据明细（子表单）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 物品 | 关联表单 | 是 | 关联物品档案，筛选「物品状态 = 在用」 |
| 物品分类 | 单行文本 | 否 | 由关联数据填充，只读 |
| 计量单位 | 单行文本 | 否 | 由关联数据填充，只读 |
| 默认库位 | 单行文本 | 否 | 由关联数据填充，仓管确认节点可编辑 |
| 数量 | 数值 | 是 | 正整数，仓管确认节点可编辑 |
| 单价 | 数值 | 否 | 由参考单价填充，两位小数，可覆盖 |
| 金额小计 | 数值 | 否 | 公式：数量 × 单价，只读 |
| 行备注 | 单行文本 | 否 | — |

### 3.3 仓库库位

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 库位编码 | 单行文本 | 是 | 主键，唯一 |
| 所属区域 | 下拉单选 | 是 | A区 / B区 / C区，与编码首字母一致 |
| 库位类型 | 下拉单选 | 否 | 货架 / 地面 / 柜子 / 临时 |
| 库位状态 | 单选 | 是 | 可用 / 停用，默认可用 |
| 备注 | 多行文本 | 否 | — |

### 3.4 库存结存

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 物品 | 关联表单 | 否 | 预留关联列 |
| 物品编码 | 单行文本 | 是 | 主键口径 |
| 物品名称 | 单行文本 | 否 | — |
| 物品分类 | 单行文本 | 否 | 中文枚举值 |
| 默认库位 | 单行文本 | 否 | — |
| 当前数量 | 数值 | 是 | 非负整数 |
| 安全库存 | 数值 | 否 | 预警基准 |
| 上次盘点日 | 日期 | 否 | 盘点复核通过后更新 |

### 3.5 库存流水

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 来源单号 | 单行文本 | 是 | 关联出入库单据编号 |
| 单据类型 | 单选 | 是 | 入库 / 出库 / 退库 / 盘点调整 |
| 物品 | 关联表单 | 是 | 关联物品档案 |
| 物品编码 | 单行文本 | 是 | — |
| 变动数量 | 数值 | 是 | 可正可负 |
| 变动后结存 | 数值 | 是 | 登记后的实际结存 |
| 变动时间 | 日期 | 是 | 业务发生日期 |
| 备注 | 多行文本 | 否 | 登记说明 |

### 3.6 盘点单

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 盘点单号 | 单行文本 | 是 | 主键 |
| 盘点日期 | 日期 | 是 | 默认当天 |
| 盘点范围 | 关联表单 | 是 | 关联仓库库位，筛选「库位状态 = 可用」 |
| 盘点人 | 成员 | 是 | 默认当前登录人 |
| 盘点照片 | 附件 | 否 | 现场留证 |
| 盘点结论 | 多行文本 | 否 | — |

盘点明细（子表单）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 物品 | 关联表单 | 是 | 筛选「物品状态 = 在用」 |
| 账面数量 | 数值 | 是 | 非负整数 |
| 实盘数量 | 数值 | 是 | 非负整数 |
| 差异 | 数值 | 否 | 公式：实盘数量 − 账面数量，只读 |
| 差异原因 | 单行文本 | 条件必填 | 差异不为零时必填 |
| 行备注 | 单行文本 | 否 | — |

## 4. 数据口径

| 口径 | 说明 |
| --- | --- |
| 主键 | 物品以物品编码为唯一口径；单据以单据编号为唯一口径 |
| 结存与流水 | 结存表记录当前状态，流水表记录变动历史，事后对账以流水为依据 |
| 停用 | 停用物品保留档案、不参与下游单据选择，不删除记录 |
| 关联列 | 关联表单列存关联记录标识，批量数据以编码类普通字段定位 |
| 低库存预警 | 当前数量低于报表预警阈值的物品列入清单，阈值在报表条件中配置 |
| 报表统计 | 数据看板仅统计已办结的流程实例 |
| 精度 | 金额类字段保留两位小数；数量类字段为整数 |
