# 通用人事管理系统 · 数据字典与编号规则

## 1. 编号规则

| 对象 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 工号 | `EMP-{4位序号}` | `EMP-0031` | 连续编制，不跳号、不复用 |
| 请假单号 | `QJ-{yyyyMMdd}-{序号}` | `QJ-20261110-101` | 按业务日期与序号编制 |
| 入职单号 | `RZ-{yyyyMMdd}-{序号}` | `RZ-20261110-101` | 同上 |
| 异动单号 | `YD-{yyyyMMdd}-{序号}` | `YD-20261110-101` | 同上 |
| 离职单号 | `LZ-{yyyyMMdd}-{序号}` | `LZ-20261110-101` | 同上 |

## 2. 表单清单

| 表单 | 类型 | 主键口径 | 数据量 |
| --- | --- | --- | --- |
| 员工档案 | 主数据表 | 工号 | 30 |
| 请假申请单 | 流程表单 | 单据编号 | 2 |
| 账号与权限台账 | 台账表 | 工号 + 系统名称 | 18 |
| 入职登记 | 流程表单 | 单据编号 | 1 |
| 异动申请 | 流程表单 | 单据编号 | 1 |
| 离职交接单 | 流程表单（含子表单） | 单据编号 | 1 |

## 3. 字段定义

### 3.1 员工档案

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 工号 | 单行文本 | 是 | 主键，唯一 |
| 姓名 | 单行文本 | 是 | — |
| 组织成员 | 成员 | 否 | 关联组织通讯录，预留字段 |
| 所属部门 | 下拉单选 | 是 | 行政部 / 财务部 / 人事部 / 技术部 / 市场部 |
| 岗位 | 单行文本 | 是 | — |
| 职级 | 下拉单选 | 否 | 初级 / 中级 / 高级 / 主管 / 经理 |
| 入职日期 | 日期 | 是 | — |
| 员工状态 | 单选 | 是 | 试用 / 在职 / 待离职 / 已离职，默认试用 |
| 联系电话 | 电话号码 | 是 | 仅 HR 与本人可见 |
| 证件信息 | 证件号码 | 否 | 仅 HR 可见 |
| 紧急联系人 | 单行文本 | 否 | — |
| 合同到期日 | 日期 | 否 | 合同续签预警依据 |
| 备注 | 多行文本 | 否 | 状态变更说明 |

### 3.2 请假申请单

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 单据编号 | 单行文本 | 是 | 主键 |
| 申请人 | 成员 | 是 | 默认当前登录人 |
| 所属部门 | 下拉单选 | 是 | 与员工档案口径一致 |
| 请假类型 | 下拉单选 | 是 | 事假 / 病假 / 年假 / 调休 / 婚假 |
| 开始时间 | 日期 | 是 | — |
| 结束时间 | 日期 | 是 | 不得早于开始时间 |
| 请假时长(天) | 数值 | 否 | 公式 `DAYS(DATE(结束时间), DATE(开始时间)) + 1`，含首尾整天，只读，整数 |
| 请假事由 | 多行文本 | 是 | — |
| 工作交接人 | 成员 | 否 | — |
| 证明材料 | 附件 | 否 | — |
| 紧急联系电话 | 电话号码 | 否 | — |

### 3.3 账号与权限台账

| 字段 | 类型 | 必填 | 说明 |

| 关联员工 | 关联表单 | 否 | 预留关联列 |

## 4. 数据口径

| 口径 | 说明 |
| --- | --- |
| 主键 | 人员以工号为唯一口径；单据以单据编号为唯一口径 |
| 状态变更 | 离职仅将员工状态改为已离职并保留档案，不删除记录 |
| 部门口径 | 所属部门使用统一枚举值，保证导入与报表分组一致 |
| 关联列 | 关联表单与成员列存关联记录标识，批量数据以工号定位 |
| 敏感字段 | 证件信息仅 HR 可见；联系电话仅 HR 与本人可见 |
| 请假时长 | 含首尾整天，整数；结束时间不得早于开始时间 |
| 合同到期预警 | 按到期日起止区间筛选，视图与报表使用同一区间 |
| 账号台账 | 按「员工 × 系统」一行，账号状态与开通日、回收日联动维护 |
| 未闭环清单 | 完成状态不为「已完成」的交接事项行 |
| 报表统计 | 数据看板仅统计已办结的流程实例 |

## 5. 数据量基线

| 数据集 | 记录数 | 关键分布 |
| --- | --- | --- |
| 员工档案 | 30 | 5 个部门各 6 人；在职 22 / 试用 4 / 待离职 2 / 已离职 2；年度入职 6 / 12 / 12 |
| 账号与权限台账 | 18 | 使用中 12 / 已回收 3 / 待开通 3 |
| 请假申请单 | 2 | 2 天（2 级审批）、5 天（3 级审批） |
| 入职登记 | 1 | 工号按档案序号顺延 |
| 异动申请 | 1 | 部门变更类 |
| 离职交接单 | 1 | 5 行交接事项，其中 3 行已完成、2 行未闭环 |
