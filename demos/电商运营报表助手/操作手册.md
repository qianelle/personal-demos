# 操作手册

## 1. 启动

```bat
python -m pip install flask openpyxl
python run.py
```

打开 http://127.0.0.1:5002。数据区间 2026-08-06 ~ 2026-11-08，取数时点 2026-11-09 08:20。

## 2. 经营分析

- 日期、款号、链接ID、标签选择后，点「查询」才生效；「重置」回到近7天、全部款号、链接ID 空、全部标签。
- 标签为单选下拉：全部标签 / 未打标 / 测试款 / 潜力款 / 动销款 / 主推款 / 滞销款。
- 快捷区间 4 个：昨日 / 近7天 / 近30天 / 近60天；默认近7天（11/02~11/08，对比 10/26~11/01）。
- 8 张 KPI 采用 4×2 网格；点击只切换趋势图，不影响推广两栏、计划表、筛选。
- 推广计划 16 列全部可排序，每页 10 条，两个阈值输入框默认空；点「查询」执行计划筛选，点「重置条件」清空。
- 推广计划表列宽可拖动，表头右侧「重置列宽」恢复；表头右侧「导出表格」导出当前筛选与排序后的全部计划。
- 指标说明在页面底部折叠区；ⓘ 可查看说明。

## 3. 链接管理

- 左侧「设置我的链接池」维护三个模块共享的链接池。
- 顶部 7 张标签卡：全部链接 / 主推款 / 动销款 / 潜力款 / 测试款 / 滞销款 / 未打标。
- 快捷查询字段：商品ID / 款号 / 二级品类；支持多条输入。
- 批量操作与快捷查询同一行：选择标签 → 写入所选 / 移除所选。
- 链接表表头「选择」可全选当前页；翻页、筛选、查询、切换标签卡后恢复未选。
- 表头「选择」列旁的复选框只作用于当前页；批量写入与移除只处理已勾选行。
- 链接表列宽可拖动，表头右侧「重置列宽」恢复；「导出表格」导出当前筛选与排序后的全部链接（不受 20/50/100 分页限制）。
- 高级筛选默认收起，包含数值区间与上架日期；清除筛选恢复。
- 圆圈「!」悬浮查看标签说明。

## 4. 数据报表

- 日报 / 周报 / 月报三个页签；「目标设置」按钮紧邻月报之后。
- 目标设置弹窗只有月度销售目标（万元）和月度付费占比上限（%）。
- 三卡目标达成看板：本月目标达成 / 当前付费占比 / 推广场景花费占比。
- 每个页签有 4 个可编辑文字模块，第一个预填默认正文，可手改。
- 导出按钮在文字模块下方居中，只导出当前页签。

## 5. 导出与打印

- 点击「导出日报 / 导出周报 / 导出月报」下载自包含 HTML；浏览器打开后点「打印 / 另存 PDF」。
- 图表为内联 SVG，不依赖网络；复制到项目目录之外打开仍然显示。

## 6. 数据与边界

- 数据取自订单明细 / 商品效果 / 商品推广三张源表。
- 数据覆盖 95 天，截止 2026-11-08。
- 个人练习项目、模拟脱敏数据、未接生产、无账号体系；不自动发送、不自动判定标签、不自动下架、不做财务净利与薪酬计算。
