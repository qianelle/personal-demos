# 店铺报表助手

把电商运营每天、每周、每月手工拼数与交表的活，做成能自动出数、能按标签管理链接、能直接导出日报周报月报的小工具。

个人练习项目，模拟脱敏数据，未接生产，无账号体系。

## 一、运行

```bat
python -m pip install flask openpyxl
python run.py
```

浏览器打开 **http://127.0.0.1:5002**（端口占用自动顺延；可用 `--port` 指定）。`python run.py --data-only` 只跑数据。

## 二、三个模块

| 路由 | 模块 | 内容 |
| --- | --- | --- |
| `/` | 经营分析 | 筛选、8 张 KPI、趋势、推广两栏、推广计划、指标说明 |
| `/links` | 链接管理 | 标签卡、快捷查询、高级筛选、链接表、批量标签 |
| `/reports` | 数据报表 | 日报 / 周报 / 月报、目标设置弹窗、可编辑文字模块、自包含 HTML 导出 |

单链接明细 `/item/<id>` 为二级页面。左侧「设置我的链接池」挂在经营分析下方，三个模块共享同一链接池。

## 三、日常使用

- 看数：经营分析选日期、款号、链接ID、标签，点「查询」生效；快捷区间为昨日 / 近7天 / 近30天 / 近60天。
- 管链接：顶部标签卡切换范围；快捷查询按商品ID、款号、二级品类；批量标签与查询在同一行。
- 出报表：日报 / 周报 / 月报三个页签，目标设置按钮紧邻月报；每个页签下方有可编辑文字模块和居中导出按钮。

## 四、表格操作

- 推广计划表与链接管理表的列宽可拖动调整，刷新页面后保留；点表头右侧「重置列宽」恢复。
- 链接管理表表头「选择」可全选当前页；翻页、筛选、查询、切换标签卡后恢复未选。
- 两个表格标题行右侧都有「导出表格」，导出当前筛选与排序后的全部记录（不受分页限制），格式为 xlsx。
- 导出文件名带区间与筛选摘要，例如 `推广计划_20261102-20261108.xlsx`、`链接管理_20261102-20261108_主推款.xlsx`。

## 五、导出报表

- 数据报表当前页签的「导出日报 / 导出周报 / 导出月报」生成自包含 HTML，内联 SVG 与内联 CSS，无外链，无 xlsx。
- 浏览器打开导出文件后点「打印 / 另存 PDF」即可上交；复制到项目目录之外仍可正常显示图表。
- 操作记录会在运行时自动写入 `output/` 对应日志。

## 六、目录

- `app.py`：页面与导出入口
- `config.py`：项目配置
- `src/`：数据管线、查询与页面服务
- `templates/`、`static/`：页面模板与样式脚本
- `data/`：模拟源文件与 SQLite 数据库
- `docs/`：说明文档
- `output/`：导出文件与运行日志
