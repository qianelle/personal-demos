# 演示讲稿

1. **打开**：`python run.py`，访问 http://127.0.0.1:5002。定位是把运营每天、每周、每月手工拼数、手工交表的工作变成系统自动出数。
2. **看数**：经营分析选日期、款号、链接ID、标签后点「查询」；8 张 KPI，点击只看局部趋势；推广两栏与 16 列计划表照常排序分页。
3. **管链接**：顶部标签卡切换全部 / 主推 / 动销 / 潜力 / 测试 / 滞销 / 未打标；快捷查询与批量写入、移除在同一行；高级筛选默认收起。
4. **出报表**：日报、周报、月报；目标设置按钮紧邻月报；三卡目标达成看板；下方四个文字模块可现场手改。
5. **导出**：点当前页签导出按钮，下载自包含 HTML；复制到桌面单独打开，图表仍显示；点打印 / 另存 PDF 上交。
6. **表格**：推广计划与链接表可拖动列宽并重置；链接表可全选当前页；两个表格都能把当前筛选与排序后的全部记录导出为 xlsx。
7. **边界**：个人练习项目，模拟脱敏数据，未接生产，无账号体系；不自动发送、不自动判定标签、不自动下架、不做财务净利与薪酬计算。
