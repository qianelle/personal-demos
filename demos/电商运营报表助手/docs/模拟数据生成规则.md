# 模拟数据生成规则

- 单店 shop_a，数据区间 2026-08-06 ~ 2026-11-08，共 95 天。
- 按电商后台常见导出结构生成：订单明细、商品效果、商品推广、商品主数据映射。
- 在售链接 219 条；每天约 40 条链接有成交；客单价约 150 元。
- 商品标题包含季节、材质、工艺词；标题模板保持完整。
- 季节销量权重曲线用于生成销量结构，不作为字段输出。
- 订单状态按业务分布保留：已付款 / 已发货 / 已关闭 / 退款成功 / 部分退款；退款状态与退款金额保留。
- 相似链接组作为铺货矩阵属性保留。
- 一级场景固定三类：全站推广 / 关键词推广 / 精准人群推广。
- 商品推广报表 32 列，包含加购人数与加购率。
- 不自动改状态、不自动发标签、不自动发送。
