# 指标口径字典

| 指标 | 来源 | 公式 / 说明 | 统计区间 |
| --- | --- | --- | --- |
| 销售额 | 订单明细 | 订单行级实付合计；行级实付 = 应付货款 − 优惠 + 邮费 | 订单付款日期 |
| 净销售额 | 订单明细 | 销售额 − 当期退款金额 | 订单付款日期 |
| 销量 | 订单明细 | 购买数量合计 | 订单付款日期 |
| 订单数 | 订单明细 | 子订单编号去重计数 | 订单付款日期 |
| 客单价 | 订单明细 | 销售额 / 订单数 | 订单付款日期 |
| 访客数 | 商品效果 | 商品访客数合计 | 商品效果日期 |
| 支付买家数 | 商品效果 | 支付买家数合计 | 商品效果日期 |
| 转化率 | 商品效果 | 支付买家数 / 访客数 | 商品效果日期 |
| 退款率 | 订单明细 | 退款金额 / 销售额 | 订单付款日期 |
| 推广花费 | 商品推广 | 花费合计 | 推广日期 |
| 推广成交金额 | 商品推广 | 总成交金额合计 | 推广日期 |
| 总投产比 | 商品推广 | 总成交金额 / 花费 | 推广日期 |
| 直接投产比 | 商品推广 | 直接成交金额 / 花费 | 推广日期 |
| 付费占比 | 订单 + 推广 | 推广花费 / 订单实付销售额 | 报表统计区间 |
| 推广场景花费占比 | 商品推广 | 场景 SUM(花费) / 三场景花费合计 | 当前报表页签区间 |

目标达成与趋势使用净销售额；本月累计按 11/01~11/08，时间进度 8/30。
