# 项目说明一页纸

**定位**：把电商运营每天、每周、每月手工拼数与交表的活，做成能自动出数、能按标签管理链接、能直接导出日报周报月报的小工具。

**模块**：经营分析 / 链接管理 / 数据报表；单链接明细为二级页面。

**日常流程**：看数 → 管链接 → 出报表。

- 经营分析：筛选以「查询」为准；8 张 KPI、趋势、推广两栏、16 列计划表。
- 链接管理：标签卡、快捷查询、高级筛选、批量标签；表格列宽可拖动，支持导出表格。
- 数据报表：日报/周报/月报、目标设置弹窗、可编辑文字模块、自包含 HTML 导出。

**已知边界**：个人练习项目；模拟脱敏数据；未接生产；无账号体系；不自动发送、不自动判定标签、不自动下架；不做财务净利与薪酬计算。
