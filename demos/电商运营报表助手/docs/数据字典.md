## fact_order_line

字段：shop_id、source_file、source_row_no、child_order_id、item_id、stat_date、paid_at、order_status、quantity、payable_goods_amount、discount_amount、payable_shipping_fee、line_pay_amount、refund_status、refund_amount、is_refund_completed、is_valid、issue_flags、raw_row_json。

订单行按子订单编号唯一；销售额取订单行级实付。

## fact_item_traffic_daily

字段：shop_id、stat_date、item_id、visitors、page_views、pay_buyers、pay_amount、success_refund_amount、cart_units、cart_users、favorite_users、avg_stay_seconds 等。

## fact_ad_plan_daily / fact_ad_item_daily

计划日与商品日推广数据，含一级/二级场景、计划、展现、点击、花费、成交、加购、投产比等；一级场景固定为全站推广 / 关键词推广 / 精准人群推广。

## fact_wide_daily

按日期 + 店铺 + 链接聚合的宽表，含订单、流量、推广、映射属性与转化率、退款率、客单价、投产比等计算列。

## 其他表

link_tags：人工标签；report_goals：月度目标；etl_log：运行日志；source_file_probe：源文件探测记录。
