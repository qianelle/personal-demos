# 报表模板说明

## 页面结构

数据报表有日报 / 周报 / 月报三个页签；「目标设置」按钮紧邻月报之后，打开弹窗。

目标设置包含月度销售目标（万元）和月度付费占比上限（%）。

## 页面内容

1. 关键指标：8 张卡一行展示，数值与单位分行。
2. 目标达成看板：三卡同行——本月目标达成、当前付费占比、推广场景花费占比。
3. 组合图：柱为净销售额，折线为付费占比，另有上限虚线；末点标注昨日 / 本周 / 本月。
4. 四个按序号排列的可编辑文字模块；第一个预填默认正文，其余留空。
5. 导出按钮位于文字模块下方居中，只导出当前页签。

## 可视化 HTML

- 自包含 HTML：内联 SVG + 内联 CSS，无外链，不引用前端图表库。
- 六段结构：标题 / 关键指标 8 卡 / 三卡目标达成看板 / 组合图 / 按序号文字模块 / 页脚口径。
- 页脚一行：数据来源、统计区间、净销售额与付费占比说明、个人练习项目说明。
- 打印样式：A4 纵向，文字模块不跨页，图表不跨页。
- 文件名带报表类型、区间与范围，例如 `周报_我的链接池_20261102-20261108_截止1108.html`。
