# 通用人事管理系统 · 操作手册

## 1. 角色与权限

| 角色 | 主要职责 | 数据范围与字段权限 |
| --- | --- | --- |
| HR | 维护员工档案、处理入职异动离职、HR 备案、维护账号台账 | 全部人员数据；证件信息仅 HR 可见 |
| 员工 | 发起请假申请、查看本人单据 | 本人档案中本人可见字段、本人提交的单据 |
| 审批人 | 审批请假、异动与离职交接单 | 待办范围内的单据 |
| 部门负责人 | 处理加签审批、查看本部门数据 | 本部门人员与单据 |
| IT / 行政 / 财务 | 执行离职并行处理线 | 交接单中对应类别的事项 |
| 查询角色 | 查看统计看板 | 只读 |

联系电话仅 HR 与本人可见；证件信息仅 HR 可见。

## 2. 员工档案维护

### 2.1 新增与批量导入

1. 进入「员工档案」，点击「新增」，或导出模板后批量填写。
2. 工号按 `EMP-{4位序号}` 编制，不跳号、不复用。
3. 所属部门从下拉选项中选择：行政部 / 财务部 / 人事部 / 技术部 / 市场部。
4. 员工状态默认为「试用」；填写入职日期、岗位、职级、联系电话与合同到期日。
5. 批量导入时选择「仅新增数据」，导入文件仅保留需要新增的记录行；组织成员等关联列留空。

### 2.2 状态变更

人员离职时将「员工状态」改为「已离职」并在备注中记录，不删除档案记录，保证历史可追溯。

### 2.3 视图与报表

| 视图 | 用途 |
| --- | --- |
| 在职人员 | 当前在职员工清单 |
| 试用期 | 待转正员工清单 |
| 30 天内合同到期 | 合同续签跟进，按到期日起止区间筛选 |
| 已离职 | 历史档案查询 |

看板包含在职人数、部门人数分布、年度入职人数分布与合同到期预警。

## 3. 发起请假申请

1. 进入「请假申请单」，点击「新增」。
2. 填写单据编号、请假类型（事假 / 病假 / 年假 / 调休 / 婚假）、开始时间、结束时间与请假事由。
3. 申请人自动带出，所属部门按实际情况选择。
4. 请假时长由公式自动计算，含首尾整天，无需手工填写。
5. 按需填写工作交接人、上传证明材料、填写紧急联系电话后提交；结束时间早于开始时间时无法提交。

## 4. 请假审批与备案

1. 审批人在「待我处理」中核对请假时段与事由，选择同意或退回。
2. 时长大于 3 天的单据进入部门负责人加签节点。
3. 两条路径统一进入 HR 备案节点，备案节点全部字段只读。
4. 流程结束后抄送 HR 与申请人。

## 5. 入职登记

1. 新建「入职登记」，填写单据编号、姓名、工号、所属部门、岗位、入职日期与员工状态。
2. 工号按现有档案序号顺延，员工状态默认「试用」。
3. 提交并办结后，档案与台账按流程规则更新。

## 6. 异动申请

1. 新建「异动申请」，从「关联员工」下拉选择人员。
2. 工号、姓名、变更前部门自动带出，不手工填写。
3. 选择异动类型（转正 / 调岗 / 调薪 / 部门变更 / 其他），填写变更后部门、变更后岗位、生效日期与异动原因。
4. 提交审批，办结后按流程规则更新员工档案。

## 7. 离职交接

1. 新建「离职交接单」，从「关联员工」选择人员，填写离职日期、离职原因并上传交接照片。
2. 在「交接事项」子表单中逐行登记五类事项：系统账号、资料文档、办公资产、财务借款、工作移交。
3. 每行填写事项说明、责任人、完成状态与完成日期；完成状态分为未开始、进行中、已完成。
4. 提交后由直属主管确认，随后并行分出账号回收、资产归还、借款结清、资料归档四条处理线，全部办结后流程结束。
5. 在「未闭环交接事项清单」中查看完成状态不为「已完成」的事项，导出后逐项跟进。

## 8. 账号与权限台账

按「员工 × 系统」一行维护：

| 字段 | 填写规则 |
| --- | --- |
| 工号 / 姓名 | 员工主键口径 |
| 系统名称 | OA / ERP / CRM / 邮箱 / 共享盘 / 低代码平台 / 其他 |
| 账号角色 | 只读 / 普通用户 / 部门管理员 / 审批人 |
| 账号状态 | 待开通 / 使用中 / 已回收 |
| 开通日 / 回收日 | 按实际办结日期填写 |
| 备注 | 记录回收时效说明 |

## 9. 数据看板

| 看板 | 内容 |
| --- | --- |
| 员工档案数据看板 | 在职人数、部门人数分布、年度入职人数分布、合同到期预警 |
| 请假数据看板 | 请假类型占比、部门请假时长排行、个人请假明细 |
| 入转调离看板 | 在职与待离职指标、异动类型分布、账号状态分布、已回收账号明细、未闭环交接事项清单 |

## 10. 通用说明

- 请假时长、差异类字段为只读公式字段，需修改来源字段后自动重算。
- 提交人、提交时间、修改时间等由系统自动记录。
- 报表统计以已办结的流程实例为准。
