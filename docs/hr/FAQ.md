# 通用人事管理系统 · 常见问题

## 员工档案

| 问题 | 处理口径 |
| --- | --- |
| 工号如何编制？ | 按 `EMP-{4位序号}` 连续编制，不跳号、不复用；新入职人员按现有序号顺延。 |
| 组织成员列显示短横线是什么意思？ | 该列为预留关联字段，批量导入时留空属正常显示；人员以工号唯一定位。 |
| 员工离职可以删除档案吗？ | 不可以。将员工状态改为「已离职」并在备注中记录，保留历史以便追溯。 |
| 所属部门可以自行填写吗？ | 从下拉选项中选择行政部 / 财务部 / 人事部 / 技术部 / 市场部，保证导入与报表分组口径一致。 |
| 「30 天内合同到期」视图如何筛选？ | 按合同到期日的起止区间设置两个条件，同时满足才计入，避免把远期到期记录一并筛出。 |
| 证件信息与联系电话谁可见？ | 证件信息仅 HR 可见；联系电话仅 HR 与本人可见。 |
| 年度入职人数分布按什么口径统计？ | 按入职日期所属年份聚合，仅统计入职记录。 |

## 请假申请

| 问题 | 处理口径 |
| --- | --- |
| 请假时长需要手工填写吗？ | 不需要。由公式按含首尾整天自动计算，字段只读。 |
| 开始与结束是同一天算几天？ | 按含首尾整天口径计算为 1 天。 |
| 结束时间填早于开始时间会怎样？ | 提交被阻断并提示；请假时长小于 1 天同样无法提交。 |
| 几天以上需要部门负责人加签？ | 请假时长大于 3 天时加签；不大于 3 天直接汇入 HR 备案。 |
| HR 备案可以修改申请内容吗？ | 不可以，备案节点全部字段只读。 |
| 工作交接人与证明材料必须填吗？ | 为选填项，按请假类型与实际需要填写。 |
| 报表里看不到刚提交的请假单？ | 数据看板仅统计已办结的流程实例，审批中的单据待流程结束后计入。 |

## 入转调离

| 问题 | 处理口径 |
| --- | --- |
| 入职登记的员工状态是什么？ | 初始状态为「试用」，后续通过异动申请处理转正。 |
| 异动申请的变更前部门从哪来？ | 选择关联员工后由系统自动带出，不手工填写。 |
| 离职交接单需要登记哪些事项？ | 系统账号、资料文档、办公资产、财务借款、工作移交五类，逐行填写责任人、完成状态与完成日期。 |
| 并行会签与条件分支有什么区别？ | 条件分支按优先级只执行命中最高的一条；并行分支中所有处理线同时分配，全部办结后流程才结束。 |
| 某条处理线一直没办结会怎样？ | 单据保持在待办状态，流程不会结束；可在未闭环交接事项清单中查看并导出跟进。 |
| 账号与权限台账按什么粒度维护？ | 按「员工 × 系统」一行，记录系统名称、账号角色、账号状态、开通日与回收日。 |
| 账号已回收后还需要填什么？ | 将账号状态改为已回收，填写回收日，并在备注中记录回收时效说明。 |
| 未闭环交接事项清单依据什么生成？ | 筛选交接明细中完成状态不为「已完成」的行，与流程是否办结相互独立。 |
