# 通用人事管理系统 · 流程规则说明

## 1. 请假审批流程

流程链路：发起申请 → 直属主管审批 → 分支判定 → HR 备案 → 流程结束 → 抄送 HR 与申请人

| 序号 | 节点 | 处理人 | 主要动作 |
| --- | --- | --- | --- |
| 1 | 发起申请 | 申请人 | 填写请假信息并提交 |
| 2 | 直属主管审批 | 流程指定的审批人 | 核对时段与事由，同意或退回 |
| 3 | 分支判定 | 系统 | 按请假时长决定是否进入加签 |
| 4 | 加签：部门负责人 | 部门负责人 | 时长大于 3 天时执行 |
| 5 | HR 备案 | HR | 登记备案，全部字段只读 |
| 6 | 流程结束 | 系统 | 归档单据实例 |
| 7 | 抄送 | 系统 | 通知 HR 与申请人 |

### 分支规则

| 优先级 | 条件 | 路径 |
| --- | --- | --- |
| 1 | 请假时长(天) 大于 3 | 进入加签：部门负责人审批 |
| 其他情况 | 时长不大于 3 | 直接进入 HR 备案 |

两条出口汇入同一个 HR 备案节点，不产生独立流程出口。

### 提交校验

| 规则 | 处理 |
| --- | --- |
| 结束时间早于开始时间 | 阻断提交并提示 |
| 请假时长小于 1 天 | 阻断提交并提示 |

## 2. 异动审批流程

流程链路：发起异动 → 原部门负责人审批 → 新部门负责人审批 → HR 确认 → 流程结束

异动类型为调薪时，薪资相关字段仅 HR 可见。审批节点中全部字段为只读。

## 3. 入职登记流程

流程链路：发起入职登记 → HR 确认 → 流程结束

办结后员工档案新增一条记录，员工状态为「试用」，并生成账号开通待办。

## 4. 离职交接流程（并行会签）

流程链路：发起离职交接 → 直属主管确认 → 并行分支（四条处理线全部办结）→ 流程结束 → 抄送 HR

| 并行线 | 处理事项 | 对应交接类别 |
| --- | --- | --- |
| 账号回收 | 回收各系统账号并更新账号与权限台账 | 系统账号 |
| 资产归还 | 收回办公资产与门禁权限 | 办公资产 |
| 借款结清 | 结清备用金与借款 | 财务借款 |
| 资料归档 | 归档资料文档并完成工作移交 | 资料文档、工作移交 |

并行分支中所有处理线同时分配，全部办结后流程才可结束；任一线未完成，单据保持在待办状态。

### 交接事项与闭环清单

「交接事项」子表单按五类逐行登记，完成状态分为未开始、进行中、已完成。入转调离看板中的「未闭环交接事项清单」筛选完成状态不为「已完成」的行，用于跟进。

## 5. 节点字段权限

| 节点 | 字段权限 |
| --- | --- |
| 请假审批节点 | 全部字段只读 |
| HR 备案节点 | 全部字段只读 |
| 离职交接并行处理节点 | 可维护本处理线对应的交接事项行，主表字段只读 |
| 异动审批节点 | 全部字段只读；调薪相关字段仅 HR 可见 |

## 6. 流程操作

| 操作 | 适用节点 | 说明 |
| --- | --- | --- |
| 同意 | 全部审批与执行节点 | 推动流程进入下一节点 |
| 退回 | 审批节点 | 退回至之前节点，重新提交逻辑由退回操作人选择 |
| 收回 | 发起节点 | 申请人撤回尚未办结的单据 |
| 抄送 | 流程结束 | 通知相关角色 |

## 7. 报表统计口径

数据看板仅统计已办结的流程实例；未闭环交接事项清单以交接明细的完成状态为准，与流程是否办结相互独立。
