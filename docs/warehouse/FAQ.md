# 通用仓库管理系统 · 常见问题

## 物品主数据

| 问题 | 处理口径 |
| --- | --- |
| 物品编码如何编制？ | 按 `WL-{分类缩写}-{4位序号}` 编制，缩写须与分类一致：BG 办公用品、BZ 包装耗材、QJ 清洁用品、SB 设备配件、QT 其他。 |
| 如何避免编码重复？ | 批量导入前在 Excel 中对编码列做重复值检查；导入后按编码排序核对连续性与记录总数。 |
| 批量导入为什么会产生重复记录？ | 导入文件中包含系统已存在的记录时，「仅新增数据」会将其作为新记录插入。导入文件应仅保留增量数据行。 |
| 物品不再使用可以删除吗？ | 不删除。将「物品状态」改为「停用」并填写原因，保留历史档案；停用物品不再出现在下游单据中。 |
| 列表中某些列显示短横线是什么意思？ | 表示该字段为空，例如未上传图片或未填写备注，属正常显示。 |
| 按分类视图依据什么排序？ | 依据物品编码升序。编码内嵌分类缩写，同缩写记录自然聚合为一段。 |
| 分类或计量单位可以自行新增选项吗？ | 由主数据维护人统一维护，避免同一事物出现多种叫法。 |

## 出入库申请

| 问题 | 处理口径 |
| --- | --- |
| 为什么搜不到某个物品？ | 该物品已被标记为「停用」，关联表单仅展示「物品状态 = 在用」的记录。 |
| 选中物品后分类、单位、库位、单价还需要手工填吗？ | 不需要，这些字段由关联数据自动带出；若为空，说明对应物品档案中该字段未填写。 |
| 总数量与总金额可以修改吗？ | 不可以，两者为只读汇总公式。修改明细行的数量或单价后自动重算。 |
| 哪些单据需要仓库负责人加签？ | 总金额大于 5000，或单据类型为出库且总数量大于 50。分支按优先级判定，命中任一即加签，且只加签一次。 |
| 仓管为什么不能修改单据编号和事由？ | 仓管确认节点仅开放数量、单价、默认库位三个字段，其余字段只读，以保证申请原始信息不被改写。 |
| 实际单价与参考单价不一致怎么办？ | 在仓管确认节点直接修改单价，金额小计与总金额会同步重算。 |
| 报表中看不到刚提交的单据？ | 数据看板仅统计已办结的流程实例，审批中的单据待流程结束后计入。 |
| 提交错误如何撤回？ | 尚未办结时由申请人在发起节点执行「收回」；审批人可执行「退回」，退回范围与重新提交逻辑在流程中配置。 |

## 台账与盘点

| 问题 | 处理口径 |
| --- | --- |
| 库存结存与库存流水有什么区别？ | 结存表记录「现在有多少」，流水表记录「怎么变的」。两表分开存储，事后对账以流水为依据。 |
| 变动数量可以填负数吗？ | 可以。入库为正、出库为负、退库按实际方向填写；该字段允许正负值。 |
| 低库存预警清单依据什么生成？ | 当前数量低于报表预警阈值的物品列入清单，阈值在报表条件过滤中配置。 |
| 盘点差异如何计算？ | 差异 = 实盘数量 − 账面数量，由公式自动计算；差异不为零时须填写差异原因。 |
| 盘点复核完成后哪些数据会更新？ | 更新库存结存中的「上次盘点日」，盘点单及明细归档留存。 |
| 流水中的来源单号有什么作用？ | 关联到对应的出入库单据，保证每笔变动可追溯到原始业务单据。 |
