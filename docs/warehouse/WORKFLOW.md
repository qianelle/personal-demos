# 通用仓库管理系统 · 流程规则说明

## 1. 出入库审批流程

流程链路：发起申请 → 主管审批 → 分支判定 → 仓管确认 → 流程结束 → 抄送申请人

| 序号 | 节点 | 处理人 | 主要动作 |
| --- | --- | --- | --- |
| 1 | 发起申请 | 申请人 | 填写单据与明细并提交 |
| 2 | 主管审批 | 流程指定的审批人 | 核对申请内容，同意或退回 |
| 3 | 分支判定 | 系统 | 按分支规则决定是否进入加签节点 |
| 4 | 加签：仓库负责人 | 仓库负责人 | 命中规则时执行，未命中则跳过 |
| 5 | 仓管确认 | 仓管 | 核对实物并确认，可编辑指定字段 |
| 6 | 流程结束 | 系统 | 归档单据实例 |
| 7 | 抄送申请人 | 系统 | 通知申请人处理结果 |

## 2. 分支规则

分支间按优先级判定，仅执行优先级最高的分支。

| 优先级 | 条件 | 路径 |
| --- | --- | --- |
| 1 | 总金额 大于 5000 | 进入加签：仓库负责人 |
| 2 | 单据类型 等于 出库 且 总数量 大于 50 | 进入加签：仓库负责人 |
| 其他情况 | 以上均不满足 | 直接进入仓管确认 |

加签节点完成后统一汇入仓管确认节点，两条路径不产生独立流程出口。

## 3. 节点字段权限

### 3.1 仓管确认节点

| 字段 | 权限 |
| --- | --- |
| 数量 | 可编辑 |
| 单价 | 可编辑 |
| 默认库位 | 可编辑 |
| 单据编号、单据类型、申请日期、申请人、申请部门、总数量、总金额、事由、凭证附件 | 只读 |
| 单据明细中的物品、物品分类、计量单位、金额小计、行备注 | 只读 |

### 3.2 审批节点

主管审批与仓库负责人节点中，全部字段为只读，审批人仅可执行同意、退回等操作。

## 4. 流程操作

| 操作 | 适用节点 | 说明 |
| --- | --- | --- |
| 同意 | 全部审批与执行节点 | 推动流程进入下一节点 |
| 退回 | 主管审批、加签、仓管确认 | 退回至之前节点，重新提交逻辑由退回操作人选择 |
| 收回 | 发起节点 | 申请人撤回尚未办结的单据 |
| 抄送 | 流程结束 | 将处理结果通知申请人 |

## 5. 盘点复核流程

流程链路：发起盘点 → 仓库主管复核 → 流程结束 → 抄送盘点人

盘点明细中差异不为零时，差异原因为必填项；复核通过后更新库存结存的「上次盘点日」。

## 6. 单据状态与数据看板口径

数据看板仅统计已办结的流程实例，审批中的单据不计入金额趋势、类型占比与排行统计。
